# University Library Management System Using Java

## Project Overview
The University Library Management System is a Java-based console application that helps manage library books and their availability.

## Features
- View all books
- Search books by title
- Count available books
- Borrow books
- Return books
- Add new books
- Remove books
- Save book records permanently using file handling

## Technologies Used
- Java
- VS Code
- Git and GitHub
- File Handling (`books.txt`)

## Project Files
- `Main.java` – Main menu and program execution
- `Book.java` – Book details and availability
- `Admin.java` – Add, view, search, and remove books
- `User.java` – Borrow and return books
- `LibraryStorage.java` – Save and load book records
- `books.txt` – Stores book records

## How to Run
1. Open the project in VS Code.
2. Run `Main.java`.
3. Select an option from the menu.
4. Follow the instructions displayed in the terminal.
